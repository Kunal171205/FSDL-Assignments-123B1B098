# Personal Profile Website

## Objective
A modern, responsive personal profile website displaying bio, skills, education, projects, coding profiles, and contact details.

## Technologies Used
- HTML5, CSS3, JavaScript (ES6+)
- FontAwesome Icons & Devicon
- AOS (Animate on Scroll)
- tsParticles

## Features
- Navigation bar with smooth scrolling
- Dynamic Hero Section with avatar and CGPA badge
- Interactive Skills & Projects showcases
- Links to LeetCode, CodeChef, CodeForces, HackerRank profiles
- Responsive design across desktop, tablet, and mobile displays
